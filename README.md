## Excel 导出

在 P16 运行导出前检查并进入 P17。确认预览版本后点击“确认导出 Excel”；保险名单还必须填写用途并勾选二次确认。生成成功后页面显示文件名、大小和 SHA-256 摘要，并提供登录态保护的下载入口。源数据变化后必须刷新预览并重新生成，旧导出文件不能继续下载。

开发机的脱敏验收样本位于 `test-results/t25-excel-samples/`，哈希清单和任务级证据见 `docs/qa/t25-excel-exports-acceptance.md`。样本仅用于验证，不得替代真实业务样表复核。

## 记录追查

P19 可按日期、项目、记录分类、操作类型、资料/对象类型和结果查询导入批次、导出记录与关键操作。失败原因可展开，每条记录可跳回源业务页面；记录只读，响应不返回受控文件路径，历史摘要会再次清除身份证号、导游证号和本机路径。任务级证据见 `docs/qa/t26-records-acceptance.md`。

## 运行新版开发环境

环境要求：Node.js 24，依赖已安装。

```powershell
npm.cmd run dev
```

打开 `http://127.0.0.1:4173`，开发解锁口令为 `local-dev`。该模式只允许模拟或脱敏数据。

开发模式另提供本地进度看板：`http://127.0.0.1:4173/dev-progress`。它直接读取 `tasks.md` 中 T01—T30 的状态、实际实现、剩余缺口和验收要求，不另建第二份进度数据。执行 `npm.cmd run check` 会把本次检查的开始时间、结果、测试数量和退出码记录到 `.runtime/dev-progress/latest-check.json`；源码或任务文件在通过结果之后发生变化时，看板会把该结果标记为“已过期”，不会继续冒充当前通过。该入口只在 `npm.cmd run dev` 的本地开发模式开放，正式启动模式返回 404。

正式启动不会使用默认口令；必须先在当前进程环境设置 `WORKBENCH_UNLOCK_PASSWORD`：

```powershell
$env:WORKBENCH_UNLOCK_PASSWORD = '请使用公司确认的强口令'
$env:WORKBENCH_SENSITIVE_KEY = '请使用独立且稳定保存的高强度敏感字段密钥'
npm.cmd start
```

新版检查：

```powershell
npm.cmd run test:database
npm.cmd run check
```

## 本地备份与恢复

解锁后打开“数据备份”进入 P20。备份默认包含 `.runtime/data/workbench.sqlite` 与 `.runtime/certificates/`，清单和备份文件保存在独立的 `.runtime/backups/`。每个备份都会校验文件大小、SHA-256、清单一致性和 SQLite 完整性；只有校验成功后才执行 30 个日备份与 12 个按月备份的轮转。

恢复前默认再生成一个受保护的当前数据副本，并要求输入备份编号进行二次确认。当天没有成功且已校验的备份时，首次正常退出会提供“立即备份并退出 / 暂不退出 / 仍然退出”三个动作；直接退出会留下审计记录。不要手工编辑备份目录中的数据库或 `manifest.json`，否则完整性校验会拒绝恢复。

## 资料导入

解锁后打开“资料导入”进入 P11。支持固定 `.xlsx`、`.csv`、不含宏的 `.docx` 明确表格/分隔文本，以及复制粘贴文字；单个文件最大 5 MB，粘贴文字最大 1 MB。文件和临时行先进入 `.runtime/imports/` 隔离目录，不会在预览确认前写入正式业务表。

P12 支持人工修正字段映射、修改本批次预览值、查看行列错误、跳过重复/错误行，并选择“仅导入有效行”或“全部正确才导入”。当前学校资料已经可以确认写入 P13；班级老师、导游接龙、乘车、住宿和用餐支持模板、解析和预览，正式写入适配器在对应业务任务完成后启用。不要将公式或宏作为资料导入，Excel 公式单元格会被拒绝，旧版 `.xls` 请先另存为 `.xlsx`。

## 导游库与档案

解锁后打开“导游库”进入 P14，可按姓名/手机号、合作状态、证件状态和常住区域筛选。P15 保存基础资料、身份证/导游证有效期、受控证件图片以及已结束项目的带团事实；完整证件值和图片必须填写用途并再次确认，普通列表和详情只显示脱敏值。

正式环境的 `WORKBENCH_SENSITIVE_KEY` 必须独立于解锁口令并稳定保存；直接更换或丢失该密钥会导致既有完整证件值无法解密。T27 和公司 Windows 目录 ACL 现场验证完成前，不得录入真实证件。

## 招募通知与接龙匹配

解锁后打开“研学项目 → 招募通知与接龙导入”进入 P06，并选择项目。页面从项目日期和 P05 班级资料计算所需导游数；学校、年级和补充说明可选择写入通知。复制按钮只操作剪贴板，仍由负责人手工切换到微信粘贴发送。

粘贴最终接龙后先预览再确认。姓名与手机号同时一致且唯一才会自动匹配；同名不同号、同号不同名、缺手机号和未建档必须选择候选档案或明确保留待处理。页面保留原始文本、来源行、接龙序号和批次顺序，不读取微信群、不保存群二维码、不自动发群，也不提供在线报名。

环境要求：Node.js 18 或更高版本。

```powershell
npm.cmd run start:legacy
```

然后打开 `http://127.0.0.1:4173`。

```powershell

```

若使用 npm，可在当前 PowerShell 环境运行 `npm.cmd start` 和 `npm.cmd test`，避免系统执行策略拦截 `npm.ps1`。
