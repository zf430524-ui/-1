# T22 / P18 异常中心验收记录

日期：2026-09-16

## 验收范围

- 统一异常重算与指纹去重。
- 阻断、警告、提醒及待处理、已确认例外、已解决状态。
- P18 按项目、模块、等级、状态筛选。
- “去处理”跳转项目源页并定位源对象。
- 警告/提醒确认例外必须填写原因，阻断不可忽略。
- 修正源数据后自动关闭，重复重算不重复堆积。
- 全项目完成门禁及完成后核心来源变化回退“待检查”。

## 关键结果

1. 同一异常重复重算保持同一编号；已确认的非阻断异常在问题仍存在时保留状态和原因。
2. 集合地点提醒与跨班拼房警告可确认例外；空原因被拒绝，阻断确认返回 `BLOCKER_CANNOT_BE_IGNORED`。
3. 修改集合地点后原提醒自动转为“已解决”，保留首次产生、最近校验、解决时间和例外原因。
4. 无阻断项目可推进“已完成安排”；完成后修改班级人数，项目自动回退“待检查”并产生乘车人数阻断。
5. P18 浏览器完成项目筛选、提醒确认、重新校验、源页定位和已解决追查；1366×768 页面无整体横向溢出，控制台错误为 0。
