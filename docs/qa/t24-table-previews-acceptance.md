# T24 / P16、P17 表格中心与实时预览验收记录

- 日期：2026-09-16
- 状态：`DONE`
- 数据范围：仅使用内存 SQLite 和脱敏测试数据

## 已验证

1. P16 固定显示保险名单和乘车安排表；住宿、用餐仅在项目条件启用时出现，一日且不含餐项目只显示两类固定表格。
2. 每类表格显示数据版本、预览行数、源数据更新时间、最近导出状态和精确阻断原因；问题入口返回 P07/P08/P09/P10 或 P18。
3. P17 快照只读，不保存第二份可编辑业务数据。字段和值来自现有仓储投影及项目汇总。
4. 保险预览只返回脱敏身份证号和导游证号；API 响应不含完整号码或加密原文。
5. 乘车合计覆盖车辆、学生、随车老师、导游、总乘车人数、可用座位和空车位。
6. 住宿预览不含人员姓名，汇总住宿人数、房间数、总容量和剩余容量。
7. 用餐按餐次区分餐厅，汇总人数、建议桌数、实际桌数、容量和余位，多餐次不共用桌号统计。
8. 快照记录项目 `data_version`。修改班级人数后，状态接口和 P17 页面均将旧快照标记为过期；服务端以 `PREVIEW_STALE` 拒绝旧版本导出，以 `PREVIEW_VERSION_REQUIRED` 拒绝未预览导出。
