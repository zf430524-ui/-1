# UI/UX 设计简报（新版负责人单端）

- 状态：`APPROVED`
- 适用范围：本地单机负责人工作台 v1；2026-09-05 旧导游移动端预览范围已取消。

## 设计目标

把旅行社现有的微信群接龙、Excel 汇总和人工核对流程，转化成一套信息密度适中、异常醒目、操作路径清楚的研学派团工作台。设计优先服务高频办公，不追求营销型大图或装饰性视觉。

## 目标用户

- 唯一操作角色：旅行社研学团负责人。
- 唯一验收终端：公司本地电脑桌面端；不设计导游登录、移动端报名或在线协同页面。

## 视觉方向

- 气质：可靠、清楚、轻量、具有研学与出行属性，但不过度幼态化。
- 桌面主背景：浅灰白，减少长时间办公疲劳。
- 导航：深海军蓝，建立稳定的工作台层级。
- 品牌主色：青绿色，用于主要按钮、完成状态和关键数字。
- 提醒色：琥珀橙用于待处理，红色仅用于冲突和阻断。
- 字体：`Noto Sans SC`，已确认 Figma 中存在 Regular、Medium、Bold 等字重。
- 设计画板：1440 × 1024；产品验收最低桌面视口为 1366 × 768。

## UX 原则

1. 先展示异常和下一步，不让工作人员自己从大表里找问题。
2. 自动建议与人工调整并存，任何调整后立即重新校验。
3. 状态使用文字＋颜色，不只依赖颜色。
4. 敏感号码默认脱敏；预览稿不放真实身份证或导游证资料。
5. 复杂项目按阶段组织，避免把全部字段堆在一个页面。
6. 表格保持办公软件熟悉感，同时提供筛选、固定列和异常定位。
