# 研学团负责人工作台 v1 技术与安全架构

- 状态：`APPROVED FOR IMPLEMENTATION`
- 日期：2026-09-12
- 对应任务：T03

## 1. 选型结论

v1 使用原生 ES Modules 前端、Node.js 本地 HTTP 服务和 `better-sqlite3`。浏览器只访问同源页面与 JSON API，不直接读取 SQLite、证件、导出或备份目录。服务固定监听 `127.0.0.1`，不提供局域网和公网监听参数。

本地访问控制采用“应用解锁＋Windows 受限目录”两层边界：

1. 页面启动后必须输入本机解锁口令；业务 API 只接受有效的 HttpOnly、SameSite=Strict 会话。
2. SQLite、证件和备份目录必须放在公司指定 Windows 账户可读写、其他普通账户不可读的目录。目录 ACL 未经现场验证前，只允许使用模拟或脱敏数据。

开发命令 `npm.cmd run dev` 可启用固定开发口令 `local-dev`，页面会持续显示“仅限脱敏数据”。正式命令 `npm.cmd start` 没有 `WORKBENCH_UNLOCK_PASSWORD` 或独立稳定的 `WORKBENCH_SENSITIVE_KEY` 时拒绝启动，避免默认口令进入真实环境。敏感字段密钥不得与解锁口令共用；更换或丢失密钥会使既有完整证件值无法解密。

## 2. 运行边界

```text
浏览器（P01—P20）
  │ 同源 HTTPS/HTTP 语义；会话 Cookie；不持久化业务数据
  ▼
127.0.0.1 Node 本地服务
  ├─ 会话守卫与输入边界
  ├─ 路由/控制器
  ├─ 领域服务与统一校验（后续 T07/T22）
  ├─ 数据访问层与事务（后续 T06/T07）
  └─ 文件服务（受控读取、导出、备份）
       ├─ .runtime/data/workbench.sqlite
       ├─ certificates/
       ├─ exports/
       └─ backups/
```

## 3. 写入、失败与回滚

- 页面只提交 JSON 或受控文件上传；服务端再次执行格式、关联和业务校验。
- 单表写入在数据访问层完成；跨表保存、批量导入、恢复使用 SQLite 事务。
- 文件类写入采用临时文件→完整性检查→原子重命名；失败时删除临时文件。
- 数据库迁移前先生成可校验备份；迁移脚本按版本单向执行，失败时事务回滚并保持旧版本可启动。
- 应用关闭时停止接收新写入，等待当前事务结束后关闭数据库连接。

## 4. 目录与敏感数据

| 内容 | 默认开发目录 | 页面权限 |
| --- | --- | --- |
| SQLite | `.runtime/data/` | 不暴露路径编辑或直接下载 |
| 证件图片 | `certificates/` | 普通列表不加载；授权查看走审计接口 |
| 导入临时文件 | `.runtime/imports/` | 按系统批次编号隔离；不使用原文件名拼接路径；取消批次立即清理 |
| Excel 导出 | `exports/` | 仅由生成记录提供受控下载 |
| 备份 | `backups/` | 与导出隔离；恢复前二次确认 |

正式部署前必须由公司确认实际目录、Windows ACL、保留责任人，并完成一次备份恢复演练。完成前不得录入真实身份证号、导游证号或证件图片。

## 5. 安全与会话

- 解锁口令不写入前端、仓库或日志；只从进程环境读取。
- 身份证号和导游证号使用 `WORKBENCH_SENSITIVE_KEY` 派生的 AES-256-GCM 密钥认证加密保存；普通查询只读取脱敏号码。密钥不写入数据库、前端、仓库或日志。
- 服务端使用 `scrypt` 派生摘要并采用时序安全比较；成功后创建内存会话。
- 会话 Cookie 为 HttpOnly、SameSite=Strict、Path=/；退出立即销毁服务端会话。
- API 校验 `Host` 与 `Origin`，限制 JSON 请求体大小；错误响应不返回本机绝对路径或敏感值。
- 进程重启后全部会话失效。

## 6. 测试分层

- `test:unit`：纯函数、页面目录和状态规则。
- `test:integration`：本地服务、会话边界和后续 SQLite 事务。
- `test:e2e`：从未解锁→解锁→访问负责人端→退出的 HTTP/浏览器流程；业务主流程随 T10—T29 增补。
- `test:legacy`：仅保留旧 Demo 9 项历史回归，不计入新版完成度。

## 7. 不做

不引入云服务、多用户账号、容器、局域网部署、导游移动端，也不把旧 `localStorage` 数据迁入正式数据库。
